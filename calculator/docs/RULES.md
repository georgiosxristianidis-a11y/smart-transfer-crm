## Словарь

| Термин | По-человечески |
|---|---|
| **commit** | «сохранить игру» — работа ушла в историю, не пропадёт |
| **branch** (ветка) | отдельная дорожка, чтобы не мешать основной |
| **master** | главная дорожка, куда всё в итоге сливается |
| **worktree** | отдельная папка под ветку, чтобы агенты не толкались |
| **untracked** | файл, о котором git не знает. **Его не существует** — сотрётся молча |
| **rebase** | «переставить свою работу на свежую основу» перед вливанием |
| **squash** | склеить всю мелочёвку ветки в один аккуратный коммит |
| **merge / PR** | влить ветку в master. PR — место, где машина проверяет |
| **gate** (гейт) | команда-проверка. Должна напечатать `0`. Не напечатала — не готово |
| **card** (карточка) | одна задача = один файл = одна ветка = один коммит |
| **STOP** | граница задачи. Агент за неё не выходит, а спрашивает |
| **TTL** | срок жизни. Карточка не влилась за сессию — её надо дробить |
| **Service Worker / PWA** | то, что даёт работу без интернета. У нас пока **не работает** |
| **IndexedDB** | база внутри браузера телефона. Локальная, без копии — опасно |

## Как ставить мне задачу

```
ЦЕЛЬ:      что должно работать после
ГРАНИЦЫ:   что можно трогать
НЕ ТРОГАТЬ: что рядом и соблазнительно
```

Расплывчатое «сделай по уму» — я переспрошу, а не угадаю.

## Мои обязательства

1. **Рекомендация, а не меню.** Есть выбор — советую лучший вариант и говорю почему одной строкой. Решаешь ты.
2. **Новый термин — сразу расшифровка** одной строкой, без напоминаний.
3. **Предупреждение до, а не после.** Перед необратимым шагом — что может пойти не так и как откатить.
4. **«Готово» — это гипотеза**, пока гейт не напечатал `0`. Это касается и меня, и Gemini.

## Как жечь меньше токенов

- **Одна сессия = одна цель.** Закрыли — новый чат. Это рычаг в разы сильнее всех остальных.
- Не подключать лишние MCP-сервера в этом проекте.
- Не «прочитай весь файл» без нужды.
- Длинное исследование — отдельным агентом, в разговор приносим только вывод.

## Грабли (пополняется)

- **Правило без числа и без проверки не работает.** «Запускай build:sw» читали все, не делал никто. Теперь есть гейты.
- **Документация врёт молча.** `CLAUDE.md` обещал офлайн, которого никогда не было. Проверяй код, а не текст о коде.
- **PIN в браузере — занавеска, а не замок.** Данные видны через DevTools в любом случае.
