# Premium Input System Redesign — утверждённая спецификация

> Спасено из осиротевшего воркtree `senior-commands-reference-46d236` (2026-08-20).
> В git не попадало ни разу. Реализация не начата.

Утверждена в grilling-сессии 2026-08-15.

## Задача
Переделать логику инпутов и ввести единый premium-стиль на всё приложение
(`calculator/index.html`, `css/style.css`, `css/tokens.css`, `js/trips.view.js`,
`js/calculator.view.js`, `js/fuel.view.js`).

## Утверждённые решения

1. **Дизайн-язык**: Recessed Tactile (Oura-style) — единственный. Убрать конкурирующую
   физику "Air Minimalism" / "VisionOS Liquid Glass" / "bio-minimalism" из контролов.
2. **Контекст**: телефон, одна рука. Нативные `date`/`time` остаются, только чинится
   тёмная тема через `color-scheme: dark` в `tokens.css` / `input`.
3. **Шкала размеров**: два тира.
   - 56px, radius 16 — поля ввода, главные кнопки.
   - 44px, radius 12 — чипы, пиллы, сегменты, иконки, степпер (порог WCAG 2.2 Target Size).
4. **Форма трансфера**: один bottom-sheet на нативном `<dialog>` + `showModal()`
   (Escape/фокус-трап/`::backdrop` бесплатно). Заменяет `modal-add-trip` div-оверлей.
   - Обязательны: дата, время, Куда, Цена. Имя и Откуда — опциональны.
   - Валидация на `blur`, инлайн-текст ошибки под полем, кнопка «Сохранить» всегда
     активна (не disabled) — при сабмите с ошибкой скроллит к первому проблемному
     полю + `navigator.vibrate`.
   - Локация «Откуда/Куда»: свой sheet с поиском + блок «Часто» (по реальной частоте
     из истории поездок) + словарь Крита группами. Полностью заменяет `<datalist>`.
   - Чинится логика чипов (`trips.view.js:93-106`) — сейчас после заполнения обоих
     полей чипы навсегда перестают работать.
5. **Цена**: `<input type="text" inputmode="decimal">`, без предзаполненного `value`
   (только `placeholder`), + ряд быстрых цен по частоте из истории. Убирает баг:
   `type="number"` даёт пустую строку при вводе через запятую (RU/EL locale) →
   `parseFloat('') || 0` → трансфер сохраняется с ценой 0 молча.
6. **Калькулятор**: слайдеры + тап по числу → точный ввод с клавиатуры.
   - Залитый трек (сейчас пустой), `::-moz-range-*` (сейчас только `-webkit-`),
     `aria-valuetext` с единицей ("45 евро", не "45"), палец — индиго
     (сейчас `--brand-secondary` cyan, не в тон остальному UI).
7. **Цветовая семантика**: цвет = только состояние.
   - Индиго = действие/выбрано, elite-pink = деструктив, янтарь = внимание, тил = успех.
   - Новый токен `--action-error` (мягкий коралл, можно взять базой
     `--status-delayed-fg: #fb7185`) — ОТДЕЛЬНО от `--action-danger` (elite-pink),
     чтобы «ошибка в поле» не читалась как «удалить».
   - Источники заказов (`source-pill`, `source-tag-*`) теряют цвет — только иконка
     на одном нейтральном фоне (`text-mid`). Убрать 5 rgba-пар в `style.css:944-948`
     и `959-...`.
8. **Модалки**: все на нативном `<dialog>` + `showModal()` — форма трансфера, настройки
   калькулятора, Driver HUD, sheet выбора локации. Заменяет `div.modal-overlay` +
   `classList.toggle('hidden')` (текущая реализация без фокуса/Escape/трапа —
   см. карточку 12 в `docs/handoff/cards/12-modals-a11y-and-blocking-dialogs.md`).
9. **Свайп-действия на карточке поездки**: оставить свайп (быстрый путь для одной руки)
   И добавить видимые кнопки-действия на карточке (Завершить/Удалить) — два пути к
   одному действию, второй путь работает с клавиатуры/тапа/скринридера.
