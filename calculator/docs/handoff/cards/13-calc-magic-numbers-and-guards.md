# 13 — Магические числа и деление на ноль в ядре расчётов

**Приоритет:** P2 · **Область:** Бизнес-логика · **Оценка:** 1–2 ч

## Проблема 1: расход топлива зашит в формулу

`calculator.store.js:101`:

```js
const litersNeeded = (totalKm / 100) * 8.7;
```

`8.7` л/100 км — ключевой параметр юнит-экономики минивэна — единственное число
в расчёте, которое нельзя настроить, хотя рядом настраивается всё: цена топлива,
км на поездку, коэффициент холостого пробега, интервалы ТО. Замена машины или переход
на дизель ломает всю модель, и починить это может только программист.

Аналогично `calculator.store.js:91` — НДС `1.13` и `calculator.store.js:116` —
резерв `0.05` зашиты в код. НДС меняется законом, а не релизом.

## Проблема 2: нет защиты от нуля

`getCalculations()` делит на `s.seasonDays` (строка 122) и `s.ownersCount`
(строки 124-125, 128). Ни одно значение не валидируется:

- `seasonDays = 0` → `dailyNet = Infinity` → `formatCurrency(Infinity)` → «€∞» на экране
- `ownersCount = 0` → то же самое
- `NaN` из повреждённого localStorage протечёт через все метрики молча

Слайдеры сейчас ограничивают диапазон в HTML, но state приходит ещё и из localStorage
(`loadFromStorage`) без всякой проверки — то есть гарантии нет.

## Проблема 3: интервалы ТО делятся без проверки

`calculator.store.js:104-106`: `totalKm / s.oilInterval` и т.д. — при нулевом
интервале те же `Infinity`.

## Что сделать

1. Вынести `8.7`, `1.13`, `0.05` в `this.state` (`fuelConsumptionPer100km`, `vatRate`,
   `safetyNetRatio`) и вывести в модалку настроек — там уже есть место.
2. Добавить санитайзер, применяемый и в `update()`, и в `loadFromStorage()`:

```js
const clamp = (v, min, max, fallback) =>
  (Number.isFinite(v) && v >= min && v <= max) ? v : fallback;
```

с таблицей допустимых диапазонов на каждое поле. Неизвестные ключи из localStorage
отбрасывать, а не сливать в state.
3. Тесты: `seasonDays = 0`, `ownersCount = 0`, `oilInterval = 0`, повреждённый JSON
   в localStorage — во всех случаях метрики конечны, на экране нет `∞` и `NaN`.

## Критерий приёмки

`npm test` содержит тест на граничные значения; ни одна метрика в `getCalculations()`
не может вернуть `Infinity` или `NaN` при любом содержимом localStorage.
