# 01 — Сломан offline: манифест Service Worker отстал от кода

**Приоритет:** P0 · **Область:** PWA / персистентность · **Оценка:** 1–2 ч

## Проблема

`ASSETS` в `sw.js` и в `scripts/build-sw.mjs` — захардкоженный список, который не обновляли
при добавлении вкладки «Топливо» и сервиса рейсов. Отсутствуют:

- `./js/fuel.store.js`
- `./js/fuel.view.js`
- `./js/shared/flight.service.js`
- `./manifest.json`, `./favicon.ico`

`app.js` статически импортирует `fuel.store.js`. Стратегия в `sw.js:45` — cache-first с
сетевым фолбэком. Значит offline: модуль не в кэше → `fetch` падает → ошибка загрузки ESM →
**не стартует всё приложение целиком**, не только вкладка топлива. Для offline-first PWA
это отказ продукта, а не деградация.

Второй дефект: `index.html:15` грузит **Chart.js 4.4.0**, а кэшируется **4.4.1**
(`sw.js:16`, `build-sw.mjs:17`). Кэш заполняется URL-ом, который страница никогда не
запрашивает → offline график не рисуется, а `new Chart(...)` в `calculator.view.js:222`
выбрасывает `ReferenceError` (проверки на существование глобала нет).

Третий: `sw.js` правили руками (`CACHE_NAME = 'taxi-crm-v1'`, `SCOPE_PREFIX`), хотя
`CLAUDE.md` прямо запрещает это. Генератор пишет `unit-calc-v${Date.now()}` — то есть
следующий `npm run build:sw` откатит имя кэша и осиротит `SCOPE_PREFIX` (константа уже
не используется нигде).

## Что сделать

1. В `build-sw.mjs` заменить ручной список на обход файловой системы (`fs.readdirSync`
   рекурсивно по `js/`, `css/`) + явный хвост внешних URL. Список не должен требовать
   ручной синхронизации — именно она и сломалась.
2. Свести версию Chart.js к одной константе; проверить, что кэшируемый URL байт-в-байт
   равен тому, что в `index.html`.
3. Удалить мёртвый `SCOPE_PREFIX` или начать его использовать в фильтре `activate`.
4. Добавить `if (typeof Chart === 'undefined') return;` в `renderChart` — график
   не должен ронять вкладку калькулятора.
5. Сменить стратегию: HTML — network-first (иначе релиз не доедет до пользователя),
   статика с хэшами — cache-first.

## Критерий приёмки

DevTools → Network → Offline → полная перезагрузка: открываются все 4 вкладки,
консоль без ошибок, график отрисован.
