# 12 — `alert`/`confirm` и модалки без клавиатуры и фокуса

**Приоритет:** P2 · **Область:** UX / доступность · **Оценка:** 2–3 ч

## Проблема

Проект прошёл LHCI на 100% (коммит `c725940`), но Lighthouse не проверяет
интерактивную доступность — а именно там дыры.

**Блокирующие системные диалоги** в приложении уровня «premium CRM»:
- `trips.view.js:144` — `alert('Нет активных трансферов...')`
- `trips.view.js:300` — `confirm('Удалить поездку?')` прямо посреди жеста свайпа
- `trips.view.js:403` — `alert('Рейс синхронизирован с радаром!')` (см. карточку 02)

`confirm` внутри `pointerup` особенно вреден: он замораживает поток, ломает инерцию
жеста и на iOS может быть подавлен браузером — тогда удаление произойдёт без
подтверждения либо не произойдёт вовсе.

**Модалки** (`modal-add-trip`, `modal-calc-settings`, `modal-driver-hud`) открываются
и закрываются простым `classList.toggle('hidden')`:
- нет `role="dialog"` / `aria-modal="true"` / `aria-labelledby`
- фокус не переносится внутрь и не возвращается на кнопку-триггер при закрытии
- нет ловушки фокуса — Tab уводит на элементы под оверлеем
- `Escape` не закрывает
- клик по подложке не закрывает
- контент под модалкой не получает `inert` / `aria-hidden`

Для водителя за рулём это ещё и вопрос скорости: лишние точные тапы вместо Escape/тапа мимо.

## Что сделать

1. Заменить `alert`/`confirm` на неблокирующие элементы: тост для сообщений,
   undo-снекбар для удаления («Поездка удалена · Отменить», 5 сек) — это лучше
   подтверждения, потому что не прерывает жест и прощает ошибку.
2. Перевести модалки на нативный `<dialog>` + `showModal()`: Escape, ловушка фокуса,
   `::backdrop` и `inert` фона достаются бесплатно. Поддержка — все целевые браузеры.
   Если `<dialog>` не подходит по стилям, реализовать вручную весь список выше.
3. Кнопкам-иконкам (`btn-global-settings`, `trip-gcal-btn`, `btn-sync-flight`) добавить
   `aria-label` — сейчас у них только `title`, скринридер в ряде случаев его не озвучит.
4. Проверить, что размер тап-таргетов ≥ 44×44 px для управления на ходу.

## Критерий приёмки

Полный сценарий (добавить поездку → настройки → HUD → удалить) проходится только
с клавиатуры; фокус ни разу не уходит под оверлей и возвращается на триггер.
