# Handoff: Smart Calculator PWA (Minivan Transfers)

## Цель (Target)
Создание PWA калькулятора для оценки юнит-экономики трансферного бизнеса на Крите (1 минивэн, чек €45).

## Архитектура
- **Стек**: Vanilla JS (ESM), нативный CSS, Store/View pattern.
- **Дизайн**: Air Minimalism (фиолетово-неоновый градиент, glassmorphism). Токены в `css/tokens.css`.
- **Безопасность**: Запрет на сырой `innerHTML`. Использование `html\`...\`` (tagged template эскейпер).
- **Хранение**: `LocalStorage` (offline-first).

## Ключевая Логика (Store)
- Выручка (с вычетом 13% НДС).
- Холостой пробег (+30%).
- Износ (масло, сцепление) динамически по пробегу.
- Распределение долей: Строго поровну (50/50 или 33/33/33).
- Честный день: Дневная выручка минус амортизированные на дни сезона годовые издержки (страховка, износ, резервы 5%).
