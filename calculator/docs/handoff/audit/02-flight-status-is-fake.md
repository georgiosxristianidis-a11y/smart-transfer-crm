# 02 — Статус рейса симулируется, но подаётся как live-данные

**Приоритет:** P0 · **Область:** Функционал / доверие · **Оценка:** 3–6 ч

## Проблема

`flight.service.js:66` определяет задержку рейса так:

```js
const hash = flightCode.split('').reduce((acc, c) => acc + c.charCodeAt(0), 0);
if (hash % 5 === 0) { status = 'delayed'; delayMins = 25; }
```

Это детерминированный хэш от букв кода рейса. Никакого сетевого запроса в проекте нет.
При этом UI показывает пульсирующую точку, подпись «Задержка +25м», а кнопка Sync
(`trips.view.js:396-406`) крутит спиннер 800 мс и выдаёт alert
«Рейс синхронизирован с радаром!». Коммит `1336bbb` называет это «flight radar sync».

Водитель примет решение выезжать или нет по выдуманной цифре. Это не косметический
недочёт — это ложные данные в интерфейсе принятия решений.

Сопутствующее: `extractFlightCode` (`flight.service.js:13`) использует
`/\b([A-Z0-9]{2})\s?([0-9]{3,4})\b/i`. Под шаблон попадает почти любой текст с двумя
символами и числом — `«Room 1204»`, `«ул. 25 Августа 1234»`, номер брони. Тест
(`trips.store.test.js:75-78`) проверяет только счастливые случаи, ложных срабатываний
не проверяет.

## Что сделать

Выбрать один из двух путей и довести до конца — промежуточное состояние хуже обоих:

**A. Честная заглушка (быстро, 1 ч).** Убрать hash-симуляцию и кнопку Sync. Оставить
только распознанный код рейса + ссылку на Flightradar24 (она настоящая и работает).
Статус не показывать вообще, пока нет источника.

**B. Реальная интеграция (3–6 ч).** Подключить провайдера (AviationStack / AeroDataBox /
FlightAware), ключ — через конфиг, не в репозиторий. Обязательно: кэш ответа, backoff,
явное состояние «нет связи» вместо выдуманного статуса. `flightStatusOverride` уже есть
в модели — использовать как слот для реальных данных.

В обоих случаях ужесточить регекс до валидных IATA-префиксов (буква+цифра / две буквы,
исключая заведомо небуквенные) и добавить тест на ложные срабатывания.

## Критерий приёмки

В UI нет ни одной цифры про рейс, которая не пришла из внешнего источника
или не помечена явно как «нет данных».
